# SimpMusic core — Android Auto community experiment

This branch contains the core changes used by the companion SimpMusic Dev auto10 app fork. It must be built with that companion app branch, which supplies the matching Gradle version catalog and resources.

Changes include Media3 voice/search resolution, adapter transport routing, classic car browse commands and Radio/Mix queue preservation/feedback. The app repository documents the full change map and validation. The intermittent Android Auto launcher disappearance is **not fixed**.

AI-assisted experimental code, shared for inspection. This is not an official upstream release or a human-reviewed upstream PR. Original GPLv3 license retained.
